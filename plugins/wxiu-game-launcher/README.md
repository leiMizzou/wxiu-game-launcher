# 微秀游戏启动器插件

一个面向 `https://wxiu.com/` 的开源 Codex 插件，需要同时安装并启用 OpenAI Browser 插件。

## 可以这样说

- `打开拳皇 98 游戏室`
- `看看现在谁最多，推荐三个游戏`
- `给我一个适合两个人的随机街机挑战`
- `帮我开恐龙快打，生成发给朋友的邀请链接`

插件会把游戏页面留在 Codex 内嵌 Browser 中供你操作。它不会自动登录、购买、发送邀请或加入陌生玩家的房间。

本项目不包含游戏 ROM、模拟器文件或 wxiu.com 的网站代码，也不隶属于 wxiu.com。使用者需要遵守网站规则，并合法拥有相应游戏的原版拷贝。
