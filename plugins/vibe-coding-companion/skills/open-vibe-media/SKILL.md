# Open Vibe Media

Use the installed Browser plugin and leave the requested content visible and interactive.

## YouTube

1. Reuse a suitable YouTube tab when practical; otherwise open `https://www.youtube.com/`.
2. For a named video, channel, playlist, or show, use visible site search unless the user supplied a direct URL.
3. Inspect rendered result titles and channel names before opening one. Do not guess a video URL.
4. For focus music, prefer one playlist, live stream, or long-form mix matching the requested energy and duration.
5. For learning content, tie the choice to the current repository or coding goal and explain why it fits.
6. Leave playback controls to the user unless they explicitly asked to start playing.

## X / Twitter

1. Open `https://x.com/home` or the specific profile/status URL requested.
2. Use the signed-in session for the home feed, bookmarks, lists, or own posts. If sign-in is required, leave the login page visible and ask the user to complete it.
3. Open the user's visible profile instead of guessing their handle.
4. Read and summarize only the requested visible scope.
5. Do not like, repost, follow, reply, send a DM, or publish unless separately requested. Public communication still follows the platform confirmation flow.

## Completion

- Verify the final page title or visible item.
- Leave one useful tab visible instead of creating duplicates.
- Report the exact video, channel, profile, post, list, or search that was opened.
