# Contributing

Contributions are welcome for game aliases, bilingual matching, recommendation logic, challenge templates, documentation, and safety improvements.

## Development workflow

1. Fork and clone the repository.
2. Create a focused branch.
3. Edit files under `plugins/wxiu-game-launcher/`.
4. Run `python3 scripts/validate.py`.
5. Test the plugin in a new Codex task with OpenAI's Browser plugin enabled.
6. Open a pull request describing the behavior change and the prompts used for testing.

Do not contribute ROMs, game files, copied website assets, credentials, personal data, or instructions for bypassing access restrictions.
